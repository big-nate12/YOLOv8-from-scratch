# Implementação do YOLO v8 para MS671

Esse repositório contém o código do primeiro projeto de nosso grupo de MS671
(Introdução ao Aprendizado de Máquinas Profundo), do primeiro semestre de 2026.
Ele consiste de:

- Uma implementação do modelo YOLO v3 em PyTorch escrita pelo professor João
  Florindo, com Non-Max Suppression implementada por nós;
- E uma implementação do modelo YOLO v8 em PyTorch escrita por nós, com parte do
  código para o pre- e pós-processamento de imagens retiradas do código do
  professor.

Todo o código não escrito por nós está marcado com um comentário.
